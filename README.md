## MusicPlayer 

## Sobre 

Esse projeto foi criado para fins de testes da API interna de som do java script, funciona como um tocador de musica offline atrelado a um banco de dados MySQL que é acessado via PHP como back-end de comunicação cliente-servidor.

## Funcionalidades do Projeto

- Sistema de volume sonoro
- Sistema de controle de timeline da Musica
- Sistema de Adição de Musicas Com Imagens e Nomes Customizadas
- Sistema de Seleção de Musicas 

## Tecnologias
 - HTML
 - CSS
 - JavaScript
 - PHP
 - MySQL
